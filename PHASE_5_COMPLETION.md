### **3. CONSISTENT DESIGN LANGUAGE**

All pages now share:

#### **Typography System**
- **Headings**: Fraunces (800-900 weight)
- **Body**: Plus Jakarta Sans (500-700 weight)
- **Letter-spacing**: Refined across all text
- **Line-height**: Optimized for readability

#### **Color Strategy**
- **Brand gradients**: Primary → Primary-hover
- **Multi-color accents**: Primary → Secondary → Accent
- **Semantic colors**: Consistent success/danger/warning
- **Text hierarchy**: Primary → Secondary → Muted

#### **Shadow Depth System**
```
xs → sm → md → lg
```
Applied consistently across:
- Cards
- Buttons
- Feature boxes
- Navigation
- Form containers

#### **Animation Language**
- **Lift animations**: -2px to -4px on hover
- **Ripple effects**: White overlay with expansion
- **Icon animations**: Scale and rotation
- **Cubic-bezier easing**: (0.4, 0, 0.2, 1)
- **Transition durations**: 0.2s - 0.3s

#### **Spacing Rhythm**
- 4px base unit maintained
- Better vertical spacing
- Enhanced breathing room
- Consistent padding scale
